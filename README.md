### NumPy Description

**NumPy (Numerical Python)** is a popular open-source Python library used for **numerical computing and data analysis**. It provides powerful tools for working with **arrays, matrices, mathematical operations, and large amounts of numerical data**.

The main feature of NumPy is its **N-dimensional array (`ndarray`)**, which is faster and more efficient than normal Python lists for numerical calculations.

### Key Features of NumPy

* 🔢 Supports **1D, 2D, and multidimensional arrays**
* ⚡ Performs calculations faster than Python lists
* 🧮 Provides mathematical and statistical functions
* 📊 Useful for data analysis and scientific computing
* 🔄 Supports matrix and linear algebra operations
* 🎲 Provides functions for generating random numbers
* 🤖 Widely used in **Machine Learning and Artificial Intelligence**

### Example

```python
import numpy as np

numbers = np.array([10, 20, 30, 40, 50])

print(numbers)
print(numbers * 2)
print(np.mean(numbers))
```

**Output:**

```text
[10 20 30 40 50]
[ 20 40 60 80 100]
30.0
```

### Jupyter Notebook Description

**Jupyter Notebook** is an open-source web-based application used for **writing, running, and documenting code**. It is especially popular for **Python programming, data analysis, machine learning, and artificial intelligence**.

Jupyter Notebook allows you to write code in small sections called **cells** and run each cell separately. You can also add **text, images, mathematical equations, graphs, and explanations** in the same notebook.

### Key Features

* 🐍 Supports Python and other programming languages
* 💻 Run code **cell by cell**
* 📊 Display graphs and visualizations
* 📝 Add notes and explanations using Markdown
* 🔢 Useful for NumPy, Pandas, Matplotlib, and other libraries
* 🤖 Widely used in **Data Science, AI, and Machine Learning**
* 💾 Save your work as `.ipynb` notebook files



### Example

```python
import numpy as np

numbers = np.array([10, 20, 30, 40, 50])

print(numbers)
print(np.mean(numbers))
```

**In simple words:** Jupyter Notebook provides an interactive environment where you can **write code, execute it, see the output, and explain your work in one place**.
